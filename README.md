# Cosmic Travel - Приложение для космических путешествий

Добро пожаловать в Cosmic Travel - революционное веб-приложение для бронирования космических путешествий!

## Описание

Cosmic Travel - это полнофункциональное приложение для бронирования космических путешествий, которое позволяет пользователям:

- Просматривать доступные космические рейсы
- Бронировать места на космических кораблях
- Управлять своими бронированиями
- Исследовать различные космические направления (МКС, Луна, Марс, Сатурн и др.)

## Возможности

- **Каталог рейсов**: Просмотр всех доступных космических рейсов с подробной информацией
- **Система бронирования**: Простой и интуитивный процесс бронирования
- **Управление бронированиями**: Просмотр и отмена бронирований
- **Адаптивный дизайн**: Работает на всех устройствах
- **Современный UI**: Красивый интерфейс с космической тематикой

## Установка и запуск

### Требования
- Node.js версии 14.x или выше
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd gpttest
```

2. Установите зависимости для сервера и клиента:
```bash
npm run install-all
```

Или установите вручную:
```bash
# Установка серверных зависимостей
npm install

# Установка клиентских зависимостей
cd client
npm install
cd ..
```

### Запуск приложения

#### Вариант 1: Запуск сервера и клиента отдельно

Терминал 1 - Запуск сервера:
```bash
npm start
# или для режима разработки с автоперезагрузкой:
npm run dev
```

Терминал 2 - Запуск клиента:
```bash
npm run client
```

#### Вариант 2: Запуск только сервера (для API):
```bash
npm start
```

### Доступ к приложению

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:5000
- **API Health Check**: http://localhost:5000/api/health

## API Endpoints

### Рейсы

- `GET /api/flights` - Получить все рейсы
- `GET /api/flights/:id` - Получить рейс по ID
- `GET /api/flights/search/:destination` - Поиск рейсов по направлению

### Бронирования

- `GET /api/bookings` - Получить все бронирования
- `GET /api/bookings/:id` - Получить бронирование по ID
- `POST /api/bookings` - Создать новое бронирование
- `DELETE /api/bookings/:id` - Отменить бронирование

### Пример создания бронирования

```bash
curl -X POST http://localhost:5000/api/bookings \
  -H "Content-Type: application/json" \
  -d '{
    "flight_id": 1,
    "passenger_name": "Иван Иванов",
    "passenger_email": "ivan@example.com",
    "passenger_phone": "+7 999 123-45-67",
    "num_passengers": 2
  }'
```

## База данных

Приложение использует SQLite3 для хранения данных. База данных автоматически создается при первом запуске сервера и заполняется начальными данными о рейсах.

Файл базы данных: `cosmic-travel.db`

### Таблицы:

- **flights**: Информация о космических рейсах
- **bookings**: Информация о бронированиях

## Разработка

### Серверная часть

Сервер работает на порту 5000 (можно изменить в `.env` файле).

Для режима разработки с автоперезагрузкой используйте:
```bash
npm run dev
```

### Клиентская часть

React приложение использует Create React App и работает на порту 3000.

Proxy настроен на `http://localhost:5000` для API запросов.

## Переменные окружения

Создайте файл `.env` в корневой директории (уже создан):

```
PORT=5000
NODE_ENV=development
```
